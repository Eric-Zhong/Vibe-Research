# 通用语言（Ubiquitous Language）

在此整理项目领域中的核心术语词汇表，确保分析与代码、文档使用同一套语言。

建议内容：
- 术语表：术语（中/英）、业务含义、在代码中的对应落点（类/函数/目录）。
- 易混淆术语的辨析（例如「大脑 / Brain」与「产品 / 工作台」的区别，见 `AGENTS.md`）。
- 团队约定俗成的缩写与口径（如「六阶段研究编排」）。

> 规则提醒（来自 `AGENTS.md`）：`orchestrator/src/` 中除 `src/finance/` 外是垂类无关的 Core，
> 不得出现行业词。通用语言在 Core 层需保持中立、可复用。
